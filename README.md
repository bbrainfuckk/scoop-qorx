# Qorx for Scoop

Install the free Qorx CLI on Windows x64 or ARM64. It indexes a repository locally so a coding assistant can ask for source excerpts with file and line references.

```powershell
scoop bucket add qorx https://github.com/bbrainfuckk/scoop-qorx
scoop install qorx/qorx
qorx --version
```

Follow the [CLI quickstart](https://github.com/bbrainfuckk/qorx#connect-an-mcp-client) to index your first repository and connect an MCP client. The CLI is licensed under AGPL-3.0-only.

For guided setup and automatic updates to the index when you save a file, [Qorx Void is on the Microsoft Store](https://apps.microsoft.com/detail/9NDC66CH9VL8?cid=qorx_scoop).
